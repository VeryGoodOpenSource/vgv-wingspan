Judge only how the questions are put to the user, not whether the idea is any good.

PASS if the response puts one question to the user at a time, on its own or with a short set of answers to pick from.

FAIL if it drops a long list of unrelated questions on the user at once, for example ten bullet points covering users, pricing, retention, analytics and rollout together.
