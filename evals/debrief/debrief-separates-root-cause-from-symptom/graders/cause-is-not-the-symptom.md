Judge only the text of the response.

PASS if the response names the underlying change as the cause — a backend response that stopped including an empty list field the client always expected, with no contract test between the two — and treats the blank screen and the client-side null check as, respectively, the visible symptom and a partial workaround that does not restore the feed.

FAIL if the response gives the symptom as the cause, for example "root cause: the home feed rendered an endless spinner", or presents the shipped null check as the fix with nothing left to do.
