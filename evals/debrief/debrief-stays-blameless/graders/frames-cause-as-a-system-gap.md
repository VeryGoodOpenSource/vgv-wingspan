Judge only the text of the response.

PASS if the response explains the incident through systems and process — for example a startup path that throws when the config file is absent, a test matrix that never covers a fresh install, or a review process with no build requirement — and keeps any description of human action role-neutral.

FAIL if the response assigns cause or responsibility to a person, for example "the author rushed the change through" or "the reviewer did not do their job", or if it lists an individual's conduct as a contributing factor.
